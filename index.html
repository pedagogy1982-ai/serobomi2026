버려지는 책, 다시 태어나다

다 쓴 문제집이나 낡은 책은 대부분 폐지로 버려집니다. 종이를 접어 주머니로 만들고 천연오일과 편백칩을 더하면, 방향제로 다시 태어나요. 이런 활동을 새활용(업사이클링)이라고 합니다.

  1. 헌책 페이지를 접어 복주머니 모양을 만들어요
  2. 편백칩에 천연오일을 떨어뜨려 향을 더해요
  3. 완성된 편백칩을 주머니에 채워 넣어요
  4. 키링줄로 마감하면 나만의 향기주머니 완성
  • 쓸모없어 보이는 물건도 다시 쓰일 수 있다는 걸 직접 느껴보세요
  • 가위·펀치 사용 시 손 조심해주세요

헌책 향기주머니 만들기 — 새활용 체험 부스

우리사이, 온이 운영하는 자원순환 체험 부스입니다. 버려지는 헌책·문제집을 종이접기로 복주머니 형태로 재탄생시키고, 천연오일을 더한 편백칩을 채워 향기주머니로 완성합니다. 쓸모없다고 여겨지는 물건도 간단한 활용으로 다시 쓸모 있어질 수 있다는 메시지를 전하고자 합니다.

  1. 헌책 페이지를 접어 복주머니 형태로 재구성
  2. 편백칩에 천연오일을 더해 향 입히기
  3. 완성된 편백칩을 주머니에 채워 마감
  4. 키링줄로 매듭지어 완성
  • 천연오일 향에 민감하신 분은 미리 말씀해주세요
  • 가위·펀치 사용 시 안전에 유의해주세요 (아동은 보호자 동행 권장)
  • 대기 인원이 많을 경우 순서에 따라 안내해드립니다
